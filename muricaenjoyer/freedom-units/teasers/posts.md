# Freedom Units: 10-day teaser schedule

Each day at **9:00 AM ET**, post the question card with the caption. The same evening at **7:00 PM ET**, reply to that post with the matching answer card and the reply text. Replace [link] with the published game URL.

Clocks change on Sun, Nov 1 (daylight saving time ends), so the UTC times shift by one hour from Day 7 on:
- Days 1-6 (EDT): post 13:00 UTC, reply 23:00 UTC
- Days 7-10 (EST): post 14:00 UTC, reply 00:00 UTC the next day

Ten cards, one per day, no reruns. This is the standalone teaser run. The main plan in `../../LAUNCH.md` uses three of these on its teaser days; use the rest as fillers or a second week.
