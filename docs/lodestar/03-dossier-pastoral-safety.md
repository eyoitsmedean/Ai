# Topic Dossier — Digital pastoral / IPV / suicide safety
**Bearing:** C6 · **Depth:** D4 on handoff + IPV device risk; RAINN policy still blocked  
**Why it matters:** Family-stakes. The product must interrupt, not counsel.

## Foundations
A non-clinical tool’s first duty is **interrupt → human**. IASP WHA79 (opened 2026-09-11, `docs/research/pastoral-safety.md`): handoff to a trained person, not a disclaimer-plus-list. SAMHSA: call or text 988; chat needs the site. USCCB *When I Call for Help*: safety first; no one is expected to stay in an abusive marriage; forgiveness is not permission to repeat. The Hotline (opened **this session**, 2026-09-14): 1-800-799-SAFE (7233); text START to 88788; if usage may be monitored, **call**; Escape / red X leaves immediately; clear history.

## Frontier
NNEDV Safety Net AI guides (2025, opened prior cycle): chatbots are not VAWA-confidential; they can agree with unsafe plans; stored chat on a watched device is itself harm. The Hotline now ships an “informed A.I. chat, Ruth” **as overflow when a live advocate is busy** — still behind a human line, not instead of one. **SOURCE-REPORTED** this session from thehotline.org body.

## Live controversies
- Can a faith app say anything after the numbers besides “go”? Red Letter’s answer: a **fixed** letter, never the model (D12).
- Should Leave quickly also wipe a journal? **DESIGN CHOICE / OQ4:** no, this cycle. Survivors save verses; an automatic wipe punishes that. Next Summit: an explicit “Clear this phone.”
- Escape-key-twice (The Hotline) vs one labeled button: we chose a **named** control so a reviewer is not surprised. Escape still means Close, no wipe — so a panic-Escape does not also destroy a journal the user did not ask to lose.

## Methods and limits
Opened operator and clergy pages; no RCT of Gospel chatbots. WHO SUI3 is about evaluated digital self-management, not this product. rainn.org remains Cloudflare-blocked here.

## What the top 1% know
The danger is not “forgetting 988.” It is **continuing as Advisor** after a disclosure (forgive / stay / retrieved Peace pack), and **leaving a transcript** on a shared phone. The Hotline’s masters treat exit as navigation away, not as “clear chat and keep reading.”

## Hardest objections
1. *A Gospel app should pray first.* — USCCB/FaithTrust: religion used first is a roadblock. **Answer:** numbers first; Matthew 11:28 only after, in a fixed letter.
2. *Wiping and leaving is alarming.* — The Hotline publishes the same pattern. **Answer:** label it; do not hide it behind a red X only.
3. *Journal wipe should be automatic.* — NNEDV wants less residue; a verse journal is not a disclosure log. **Answer:** OQ4 held; offer Begin again + Leave quickly for chat.
4. *Offline cannot help.* — `tel:` still works; the pack letter is not improvisation (gap closed 2026-09-11).
5. *Ruth proves AI chat is fine.* — The Hotline still leads with call/text/chat to **advocates**. Ruth is overflow. We are not an advocate service.

## Implications (what changed)
- Built Leave quickly (wipe session, `location.replace` Wikipedia).
- Built `/?fresh=1` and Begin again for demo / shared phones.
- About copy now names those controls.
- Helpline verifier script so numbers do not rot.
