# Mastery Brief — S3 Install education (Safari 26 / ITP)
**Bearing:** C4

## Who is world-class
WebKit’s own Tracking Prevention writers (Apple). Chrome’s install-criteria editors (for Android). **Evidence:** living policy pages, not Twitter threads.

## What world-class looks like
The user is told the **one toggle that decides whether their journal survives a week**: Open as Web App. Android still gets menu → Install.

## Difference that makes the difference
Good: “Share → Add to Home Screen.” World-class: name the 7-day tab cleanup and the exemption.

## Process
Detect iOS vs Android vs other → write three short steps → one honest note.

## Rubric
1. iOS copy names Open as Web App — **pass**.
2. Names 7-day tab cleanup — **pass**.
3. Does not claim a Chrome-on-iOS install — **pass**.
4. Android path unchanged in spirit — **pass**.
5. No fake `beforeinstallprompt` on iOS — **pass**.

## Practice loop
Re-read webkit.org/tracking-prevention when Safari ships a notes post that mentions ITP.

## Traps
Citing a 2023 `persist()` blog as a 7-day waiver. Teaching Add to Home Screen without “open as web app.”
