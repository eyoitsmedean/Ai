# Dossier — Lectio divina from an answer

**Topic:** Four rungs, then a product-sized subset  
**Bearing:** C8, C6  
**Why it matters:** “Amaze / beautiful” authorized a practice, not a second home screen.

## Foundations
Guigo II, *Scala Claustralium*: lectio, meditatio, oratio, contemplatio. Reading seeks, meditation finds, prayer asks, contemplation tastes. Latin/English: ldysinger.com excerpt; ecatholic2000 Guigo II. **SOURCE-REPORTED** (opened this session via search/fetch artifacts).

USCCB National Bible Week leaflet: short passage, linger on a phrase, respond. Order in that PDF lists contemplatio before oratio — a known popular variation. **SOURCE-REPORTED.**

Benedictine practice (Our Lady of Grace): four movements, not strictly linear. **SOURCE-REPORTED.**

The app already had a four-step lectio on Today’s word (Read / Notice / Sit / Respond) — a faithful popularization, not a scholarly edition of Guigo.

## Frontier
Phone lectio that starts from *the saying just given*, so craft serves the advisor.

## Live controversies
Whether an app timer profanes contemplatio. We end in the existing silence overlay and do not score it.

## What the top 1% know
Lectio without a short text is study. Contemplation without the prior rungs is a mood. Guigo: “lectio without meditatio is dry.”

## Hardest objections
1. Four Latin steps will scare the audience — *answer:* UI stays Read/Notice/Sit/Respond.  
2. This duplicates Today — *answer:* Today stays; Advisor can now enter the same overlay.  
3. AI-generated lectio prompts — *answer:* refused; the text is WEB.

## Implications (changed)
