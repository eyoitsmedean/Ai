## Purpose

## Goals

**C1. Research → build → QA → rebuild until world-class.**  
Source (stated): “Do research on how to improve the project, then do research on those topics online, then come back and build, then QA the results and rebuild and run this loop again as needed to hit a world class standard.” Prompt 1; repeated 10.

**C2. Complex in the making, simple in the using.**  
Source (stated): “impress a human… beautiful, elegant, complex in build but very simple in usage designs and things like Notion… exceed your own expectations here and be ambitious.” Prompt 2. Notion is a *quality* metaphor, not a product.

**C3. Excruciating review and an independent sign-off.**  
Source (stated): “Review the plan and research every single component in excruciating detail then apply any changes, fact check it, qa the design, UI and code… final sign off agent ensuring its world class.” Prompt 3.

**C4. Advance the project; build, do not stall.**  
Source (stated): “Do what you feel advances this project the most.” Prompt 4. “Build baby build.” Prompt 5. “Build the best thing you can imagine here.” Prompt 13.

**C5. Treat the work as if family success hangs on it.**  
Source (stated): “Research and build like my success and my families success hangs in the balance on the results.” Prompt 7. Later: “Make this production ready by tomorrow.” Prompt 15.

**C6. Only His spoken Gospel words (KJV), verified.**

**C10. Ambitious and creative; ignore side quests.**
