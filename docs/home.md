# Red Letter — project home

**What is this for?** A quiet reading room and an Advisor that will only speak the words Jesus spoke in the four Gospels (KJV).

**What has been completed?** The folio, Seven Days, one conscience path, 113/113 eval both composers, the recovery flagships, and LODESTAR Cycle 1 (one Today, crisis first-word gate, `npm run sit`, atlas, offline help).

**What should I do next?** `npm run first-word`. Then sit (`docs/flagship-sitting.md` or `npm run sit`). Then merge, then the five phone minutes.

**Where are the finished deliverables?**

| Flagship | Where | Use |
| --- | --- | --- |
| 1. One conscience path | `lib/curated.js`, `public/data/advisor.js`, morning `rotation` | Same rooms *and* the same Today. |
| 2. The Conscience Book | `docs/flagship-conscience.md` | Safety, citations, helplines. |
| 3. The Review Sitting | `docs/flagship-sitting.md` · `npm run sit` | Walk, or run the proof. |
| 4. The rooms | `public/atlas.html` | First verse, and what each room refuses. |
| 5. Help if the room fails | `public/help.html` | Numbers only. Cached first. |

**What evidence and decisions support them?** `CLAUDE.md` · `docs/BRIEF.md` · `docs/lodestar/01-charter.md` · `RELEASE.md` · `eval/results.md` · `docs/lodestar/`

**What remains unresolved?** Merge to Pages; model-path eval; on-device walk; UK KJV print; store wrappers; whether to suppress known crisis idioms (recommend no).

**How to maintain this.** Edit rooms in `lib/curated.js` and run `npm run curated`. Edit notices only in `public/data/signals.js`. Do not recreate `data/advisor.js`. Do not swap `data/red-letter-source.json`.
